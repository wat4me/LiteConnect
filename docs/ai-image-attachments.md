# AI 会话图片附件

在 AI 设置 → 服务商 → 模型详情中勾选“支持图片输入”。仅在模型与当前接口都支持图片时启用；自定义模型和中转服务由用户明确设置，旧配置默认关闭。

输入框上方的图片按钮可选择 PNG、JPEG、WebP；也支持粘贴截图和拖入图片。每条消息最多 4 张，可只发送图片。缩略图可预览、移除，历史记录中的图片可继续预览，并随后续对话、重试、编辑重发提供给模型。

- 原始图片最大 20 MiB；最长边超过 2048 像素时缩小。优先保留 PNG，过大时转换 JPEG；处理后每张最大 5 MiB，一次模型请求的图片总量最大 20 MiB。
- 现阶段支持 OpenAI 兼容的 Chat Completions 图文消息：发送时将文字和图片转换为 `text` / `image_url` 内容块，图片使用 Base64 data URL，无需图床。Claude、Gemini 原生协议需要独立适配。
- 图片字节存储在用户数据目录的 `ai-images/<主机哈希>/<内容哈希>.image` 中。会话数据库只保存引用；仅当前会话加载图片，清理历史、删除消息或会话后回收无引用文件。
- 丢失图片、未启用图片支持、接口拒绝图片会明确报错，不会退化成纯文本请求。图片上下文用估算值参与预算，实际计费由服务商返回的 usage 决定。上下文压缩会把图片提供给摘要请求，原始历史仍保留图片。

测试覆盖消息序列化、上下文打包、图片独立存储及回收、模型配置，以及真实 Electron 中的选择、粘贴、拖入、预览、删除、图片单独发送与多主题布局。测试接口使用模拟响应，不会上传图片到真实服务。
