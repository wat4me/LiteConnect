# SSH 连接与终端使用指南

## SSH 连接与重连行为

- 网络握手默认等待 20 秒。服务器要求验证码或其他交互认证时，改为等待用户输入 120 秒；提交后恢复网络等待期限。目标服务器和跳板机分别计时。
- 多个连接同时要求信任主机或输入验证码时，弹窗排队显示，并注明目标连接。连接结束、取消或认证超时后，移除过期弹窗。
- 连接列表显示网络连接、跳板机、认证、等待输入和打开终端等阶段。点击取消会终止后台握手和关联的认证请求；晚到的结果不会创建终端。
- 每个终端独立计算自动重连次数。重试采用指数退避，加入最多 25% 的随机延迟，总延迟上限 15 秒。同一目标及跳板机组合最多同时进行两个重连握手，其他终端排队；关闭终端会取消尚未完成的重连。
- 主机指纹先保存到数据库，成功后才更新内存中的信任状态。保存失败时保留原状态，避免本次看似信任成功、下次又需要确认。
- 会话日志处理磁盘背压，待写队列最多 2,000 个片段或 1 MiB。磁盘故障或队列超限时停止该会话日志写入，SSH 会话继续运行。终端快速关闭时，不会在异步初始化后重新创建日志流。

单元测试覆盖超时、取消与晚到回调、认证弹窗排队、写入错误和背压、主机指纹保存失败、并发限制与终端独立重试计数。真实服务器的 MFA 配置和跳板机认证仍应在对应环境中验证。

## 实时同步输入

在 SSH 工作区左侧点击「同步输入」（链条图标），选择至少两个可写终端，再点击「开启同步」。在任意一个选中的终端输入时，会向其他选中终端发送同样的字符，包括中文、退格、回车、Ctrl+C、Tab、方向键、命令建议补全和确认后的粘贴。未选中的终端不会发送或接收同步输入。

顶部常驻显示目标数量、名称和「停止同步」。收起目标选择后，运行提示仍保留。修改目标时先暂停，需要重新开启；断线、只读或关闭的终端会移出目标，恢复后需要重新选择。目标不足两个时自动停止。进入 Docker 工作区会停止同步。同步状态不保存到下次启动。

同步发送相同输入，不会统一远端终端的状态。开启前应确保各终端都位于预期的 shell 提示符；Tab 补全、方向键历史等结果由每台服务器自行决定。命令片段与批量执行仍使用各自的目标选择。

手工验证：

1. 打开 A、B、C 三个终端，选择 A、B，开启同步。
2. 在 A 输入 `echo sync` 并回车，确认 A、B 都执行，C 不受影响；从 B 输入也应同步到 A。
3. 测试中文、退格、方向键、Ctrl+C 和粘贴；确认没有重复字符。取消粘贴确认时，各终端都不发送内容。
4. 点击停止，再输入内容，确认只有当前终端收到。
5. 开启后修改目标，确认同步暂停，重新开启才继续。
6. 将 B 切成只读、断开连接或关闭，确认移出目标且自动停止；恢复 B 后不自动重新加入。
