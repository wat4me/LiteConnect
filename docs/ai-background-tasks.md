# SSH 后台任务状态

AI 工具可通过 `exec(background=true)` 启动独立 SSH exec 通道，再用 `get_job` 查询结果。AI 回复结束或收起面板不会终止已启动的后台命令；关闭或断开 SSH 会取消通道。普通模型思考、前台工具调用以及命令自行脱离通道创建的守护进程不属于此任务列表。

AI 面板显示当前 SSH 窗口的后台任务数量，展开可查看命令、运行状态和退出码，以及最近五条已结束任务。侧边栏 AI 按钮显示当前窗口的运行数量；主机标签和终端标签显示活动图标，切换到其他窗口仍可辨认有任务在执行的窗口。审批和未读提示保留。

状态直接读取应用共享的 SSH 工具任务存储，覆盖 AI 和外部 MCP 发起的后台命令。任务启动、结束、失败、超时或取消后，主进程推送状态更新；组件共用一个订阅，不周期性查询。初次挂载读快照，并避免较旧快照覆盖实时事件。重启应用后不恢复已关闭的 SSH 通道任务。
