# SSH 工具布局

SSH 工作区支持将工具图标停靠到左、右、顶部或底部。拖动图标时显示落点预览；右键图标也可选择停靠位置，或在当前工具栏中向前／向后排序。工具栏的布局按钮提供锁定、解锁、恢复默认布局和保存失败后的重试。

移动到另一边时，对应面板从该边展开；仅调整图标顺序时保留原面板位置。Docker 入口可移动，内容继续在中央工作区打开。默认所有图标仍在左侧，AI／文件面板在左侧，批量命令／命令片段在右侧，监控在底部，同步输入在顶部。

点击工具图标展开，再次点击收起。同一区域只展开一个工具，点击其他工具图标时切换；不同区域可以同时使用，例如左侧文件、右侧 AI。停靠容器不额外增加工具标签或标题栏，也不展示未打开的其他工具；各面板保留原来的内部界面和操作方式。监控在上／下区域默认显示摘要，点击详情在该区域展开完整面板。同步输入面板的显隐与是否启用同步输入独立，收起后中央状态条仍提供停止操作。

SFTP 文件列表使用独立的像素字号设置，图标和行高随该字号统一计算，不再因为面板变宽而自动增大。终端字号缩放仍只影响终端。

面板分隔条支持鼠标拖动及方向键调整尺寸，Shift 加快步幅，Home／End 调至允许范围的两端。拖动过程中只更新预览，结束时保存一次；Escape、指针取消或工作区卸载会放弃未提交的调整。锁定后不能移动、排序、调整尺寸或重置，工具打开／关闭继续可用。

窄窗口或较矮窗口只保留一个展开工具，使用覆盖面板给终端保留空间。其余工具可随时重新打开；已保存的停靠位置、顺序和首选尺寸不会被窗口大小覆盖。正常窗口的区域尺寸也会按可用空间收缩，防止挤出工作区。

布局是当前用户所有 SSH 连接共用的偏好，随应用重启保留，其他已打开窗口接收更新。各窗口的展开状态、AI 会话、文件目录和终端状态分别管理。Docker 模式的面板恢复沿用现有会话规则。

终端分屏只改变中央终端的排列，不收起、禁用或在退出时重新打开工具面板，同主机和跨主机行为一致。AI 绑定主终端，在原有面板标题内显示目标主机和终端；点击另一窗格只改变输入焦点，交换分屏或切换主终端才更新 AI 目标。主终端的选区可发送给 AI，次终端继续隐藏该入口以免跨会话误投。SFTP 保持原有目标终端标记。左右／上下分屏分别增加中央区域的预留宽度／高度，临时压缩停靠面板而不修改用户保存的尺寸。

## 实现

- `shared/workspaceLayout.ts` 定义工具白名单、默认布局、版本化配置、尺寸边界与移动／排序规则。新增或缺失工具补默认值，未知工具不进入界面或动态组件加载。
- `useWorkspaceLayout` 通过现有 `settings:getAll`／`settings:setMany` 读取和保存 `sshWorkspaceLayout`，使用本机 SQLite 的设置记录。读失败前禁止覆盖布局；写入串行合并后续调整，失败保留当前视图并允许重试；其他窗口事件和迟到响应有失效检查。
- `useWorkspacePanelPolicy` 在原有面板状态之上统一处理区域冲突，快捷键、AI 选区、命令片段转批量执行、Docker 快照和分屏恢复继续使用同一套状态。
- `WorkspaceDock` 持有固定的区域容器，以 Teleport 移动稳定的面板挂载点，组件实例不随停靠位置变化而重建。`SshWorkspace` 负责具体工具、会话缓存与终端事件；xterm 使用现有 ResizeObserver 更新终端尺寸。

## 验证

`npm run test:ui -- --dock` 使用隔离应用目录和真实 SQLite 设置存储，加载实际 `SshWorkspace`、AI、文件和 xterm 组件，以及生产使用的分屏状态与控制器。SSH／AI 网络由测试接口提供，不访问真实服务器或凭据。覆盖四边移动、实例与草稿保留、不同区域并排、同主机／跨主机分屏、AI 目标与主次交换、分屏期间手动收起后的状态保留、上下停靠组合和中央尺寸预留、拖拽预览、尺寸提交、锁定／重置、失败重试、重启读取、多窗口配置事件及中英文和三种主题的宽窄窗口。
