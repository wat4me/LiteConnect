# SSH 工具布局

SSH 工作区支持将工具图标停靠到左侧或右侧。拖动时两侧的窄条标出可停靠的位置，工具栏中的插入线标出图标顺序。在内容区松手会取消拖动。右键图标也可选择停靠位置，或在当前工具栏中向前／向后排序。工具栏的布局按钮提供锁定、解锁、恢复默认布局和保存失败后的重试。

移动到另一边时，对应面板从该边展开。仅调整图标顺序时保留原面板位置。Docker 入口可移动，内容在中央工作区打开。默认图标在左侧，AI、文件和同步输入面板在左侧，监控、批量命令和命令片段在右侧。

点击工具图标展开，再次点击收起。同侧一次展开一个工具，点击其他工具图标时切换。两侧可以同时使用，例如左侧文件、右侧 AI。停靠容器直接展示各面板原有的界面和操作。监控打开后直接显示详情。同步输入面板的显隐与是否启用同步输入独立，收起后中央状态条仍提供停止操作。

SFTP 文件列表使用独立的像素字号设置，图标和行高随该字号统一计算，不再因为面板变宽而自动增大。终端字号缩放仍只影响终端。

面板分隔条支持鼠标拖动及左右方向键调整宽度，Shift 加快步幅，Home／End 调至允许范围的两端。拖动过程中只更新预览，结束时保存一次。Escape、指针取消或工作区卸载会放弃未提交的调整。锁定后仍可打开或关闭工具，移动、排序、调整宽度和重置需先解锁。

窄窗口或较矮窗口只保留一个展开工具，使用覆盖面板给终端保留空间。其余工具可随时重新打开；已保存的停靠位置、顺序和首选尺寸不会被窗口大小覆盖。正常窗口的区域尺寸也会按可用空间收缩，防止挤出工作区。

布局是当前用户所有 SSH 连接共用的偏好，随应用重启保留，其他已打开窗口接收更新。旧布局读取时将顶部位置迁到左侧、底部位置迁到右侧，保留工具顺序、左右栏宽度和锁定状态。各窗口的展开状态、AI 会话、文件目录和终端状态分别管理。Docker 模式的面板恢复沿用现有会话规则。

终端分屏在中央工作区排列窗格，工具面板的展开状态独立管理，同主机和跨主机行为一致。AI 绑定主终端，在面板标题内显示目标主机和终端。点击另一窗格只改变输入焦点，交换分屏或切换主终端才更新 AI 目标。发送选区给 AI 的入口位于主终端。SFTP 显示目标终端标记。左右分屏按需收窄工具面板，为中央的两个终端预留宽度，同时保留已保存的面板宽度。

## 实现

- `shared/workspaceLayout.ts` 定义工具白名单、默认布局、版本化配置、尺寸边界与移动／排序规则。新增或缺失工具补默认值，未知工具不进入界面或动态组件加载。
- `useWorkspaceLayout` 通过现有 `settings:getAll`／`settings:setMany` 读取和保存 `sshWorkspaceLayout`，使用本机 SQLite 的设置记录。读失败前禁止覆盖布局；写入串行合并后续调整，失败保留当前视图并允许重试；其他窗口事件和迟到响应有失效检查。
- `useWorkspacePanelPolicy` 在原有面板状态之上统一处理区域冲突，快捷键、AI 选区、命令片段转批量执行、Docker 快照和分屏恢复继续使用同一套状态。
- `WorkspaceDock` 持有固定的区域容器，以 Teleport 移动稳定的面板挂载点，组件实例不随停靠位置变化而重建。`SshWorkspace` 负责具体工具、会话缓存与终端事件；xterm 使用现有 ResizeObserver 更新终端尺寸。

## 验证

`npm run test:ui -- --dock` 使用隔离应用目录和真实 SQLite 设置存储，加载实际 `SshWorkspace`、AI、文件和 xterm 组件，以及生产使用的分屏状态与控制器。SSH 和 AI 由测试接口模拟。覆盖左右停靠、旧布局迁移、实例与草稿保留、同主机和跨主机分屏、AI 目标与主次交换、分屏期间手动收起后的状态保留、中央尺寸预留、拖拽预览、尺寸提交、锁定与重置、失败重试、重启读取、多窗口配置事件，以及中英文和三种主题的宽窄窗口。
