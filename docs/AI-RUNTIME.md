# AI 执行服务

`electron/ai/executionService.ts` 提供统一的 `AiExecutionService`，供侧栏、LiteAI 工作区和后续运维计划调用。它不接收 `WebContents`、窗口或 Vue 组件，页面事件由 IPC 适配层转换成可选监听器。

## 运行入口

`run(request, observer?)` 接收四类明确身份：

- `requestId`：一次模型请求，供取消和工具确认使用。
- `historyId` 与 `target.threadId`：历史存储与具体对话，不从当前页面推断。
- `target.sessionId`：已建立的 SSH 会话，仅用于目标工具执行。
- `owner`：调用方身份；交互客户端使用数字编号，无页面执行使用字符串编号。自动化建议每次运行采用独立身份，例如 `automation:<runId>`。

存储是模型上下文的唯一来源。调用方先保存用户请求、创建目标对话，再调用执行服务。不存在的对话或已断开的 SSH 会话会在模型调用前失败，不恢复其他对话或重建已删除的历史。

交互调用沿用动态权限设置；`automation` 调用强制只读，不继承全局自动执行权限，也不等待页面确认。无人值守的修改操作尚未开放。

## 依赖与监听

设置端口提供初始化、运行配置和历史限制。历史端口负责读取、保存、图片加载及压缩检查点。工具端口复用现有 SSH MCP runtime。

`onStream`、`onRecord` 是可选的过程和持久化记录监听器。缺少监听器或监听器报错，不影响模型执行和结果保存。交互调用可提供 `onApproval`，实际确认仍通过执行服务按调用方身份校验。

## 后台任务与生命周期

后台命令绑定调用方、对话和 SSH 会话，完成后仍由同一服务续接。忙时排队，短时间内完成的任务合并投递；连续自动唤起最多三轮，新的主动调用重置预算。

`selectConversation` 只修改对应调用方的会话选择；另一个调用方不会暂停本调用方的任务。`suppressBackground` 在新建对话前禁用旧对话通知，并等待该对话正在执行的自动续接终止。`abort` 和 `resolveApproval` 校验请求所属调用方。`abort` 停止模型回复并禁用续接；中断 SSH 后台命令仍须调用 `cancel_job`，侧栏的新建对话流程已执行这两步。

监听器关闭与调用方销毁分开处理：没有页面的任务可继续执行；通过 `onDisposed` 或 `disposeOwner` 明确销毁调用方时，取消其模型请求并清理结果队列。应用退出调用 `dispose`，释放任务完成订阅并中止活动模型请求。

## 当前边界

LiteAI 工作区通过 `ai:openWorkspaceConnection` 选择已保存的连接并自动建立专用 SSH 会话，沿用凭据、主机密钥确认和交互认证流程。`electron/ai/workspaceConnections.ts` 按窗口和连接编号管理传输，合并并发连接、复用本工作区连接，关闭时校验归属；取消后迟到的连接也会释放。工作区传输不创建终端标签，不借用或关闭普通 SSH 窗口的连接。

工作区切换主机保留各主机当前对话和草稿，切换应用模块保留连接与任务。显式断开会取消该 SSH 会话的任务；窗口销毁会释放所属传输。主机验证完成通过专用事件路由回工作区，避免建立普通终端。两种界面共用执行服务与历史格式。

当前每条对话绑定一台服务器。跨主机工具选择、共享连接池/连接租约、计划配置和调度器尚未接入。执行服务仍使用调用方准备好的 SSH 会话，不自行选择主机。

验证覆盖无页面执行、无页面后台续接、只读权限、监听失败、调用方隔离、历史并发、停止、目标失效和资源释放；均使用模拟 SSH/模型，不访问真实服务器。
