# LiteConnect v1.0.13

- AI 对话按发生顺序显示工具调用和阶段结论。相邻工具步骤默认折叠，待确认操作仍直接显示。
- 最新回复完成后常驻显示用量、完成时间和操作按钮。历史回复在悬停或键盘聚焦时显示这些信息，普通回复页脚移除总耗时。
- 修复其他 SSH 会话滚动时，当前会话的 AI 操作权限菜单被关闭的问题。模型现在会收到实际的操作权限，并能区分 SSH 操作权限和本地知识库模式。
- 应用设置优先显示启动时读取的配置，并在后台刷新。首次读取超时后可重试。LiteAI 会话内的设置也可以在回复期间打开。
- LiteAI 多服务器会话简化连接状态显示，并标出尚未连接的服务器。
