# LiteConnect v1.0.4

本次更新改善连接管理和界面一致性，让 AI 执行状态更清楚，并为 SFTP 编辑与上传增加保护。

## 连接管理与布局

- 分组默认折叠，支持拖动调整侧栏宽度并记住设置；修复分组名称与数量的对齐和短名称过早截断。
- 支持当前分组与全部分组搜索，全部分组结果显示所属分组；可用方向键选择、Enter 连接。
- 支持拖动整张连接卡片，包括搜索结果跨分组移动；操作按钮不会误触拖拽。
- 连接卡片改为两行，复制、编辑和更多操作常驻显示；顶部次要操作收进“更多”。
- 搜索范围与“更多”使用统一下拉菜单；排序改为分段控件，区分说明文字与可点击选项。
- 修复标题、分组标签、SFTP 书签、数据库树和批量命令分组的文字布局；改善长名称省略和原生控件字体一致性。
- 选中与焦点样式使用主题变量，保留连接颜色标签；自定义主题高亮随强调色变量变化。

## AI 会话

- 区分请求模型、等待响应、接收思考、生成回复、准备工具、执行工具及等待审批，显示当前阶段耗时。
- 长时间没有新的模型内容时显示等待提示，避免把停止输出误认为持续思考；工具执行和审批不误报模型等待。
- 状态变化跟随最新内容，用户上翻查看历史时保留滚动位置。
- 修复停止 AI 后远端命令仍继续执行，以及告警弹窗关闭问题；改善 AI 自动执行流程。

## SFTP 编辑与上传

- 编辑器保存前检查远端内容是否变化；冲突时保留本地草稿，覆盖或重新加载需明确确认。
- 可选择保存前备份，保存后显示备份路径。
- 新增目录差异预览与单向上传，可勾选文件加入传输队列；默认仅选中新增文件，覆盖已有变化文件需主动开启。

## 使用说明

- 目录比较仅覆盖第一层普通文件，依据文件大小与修改时间；相同元信息不保证内容完全一致。子目录和符号链接跳过，不删除远端文件。
- 编辑保存可检测已发生的内容冲突，但最终检查与写入之间仍无法完全排除其他远端进程同时修改文件。
