# LiteConnect v1.0.12

本版本改进 SSH 工作区和 LiteAI 的排障体验。工具面板可停靠在工作区两侧，SFTP 可直接定位到终端最近记录的目录，AI 请求中断时会保留已执行命令的结果。

## SSH 工作区

- 工具图标可在左右两侧拖动和排序。支持调整停靠面板宽度、锁定布局与恢复默认，布局会保存并跨窗口同步。
- 分屏时保留工具面板。拖动工具时，用侧边提示标明停靠位置。
- SFTP 的「定位到终端目录」使用最近记录的目录，点击时无需向终端发送按键。仍可从菜单手动执行 `pwd` 并定位。

## LiteAI

- 对话将执行过程折叠成可展开的摘要，保留命令状态、输出和修改记录。请求中断时，正常正文与命令结果照常显示，错误详情单独展示。
- 错误详情区分未收到响应、接口返回错误和响应读取不完整，并显示可用的 HTTP 状态码或底层错误码。
- 多服务器会话支持逐台设置知识模式，并显示已启用知识的服务器数量。
- AI 可以预约后台命令。预约仍遵循现有执行权限，到期时在已连接的目标会话中运行，并将结果回送原对话。
- 改进 AI 对话历史的增量保存与加载，旧记录会按需迁移。

## 界面与文档

- 默认界面更紧凑。在「设置 → 外观」可分别调整系统文字大小和界面密度。
- 常用工具栏以图标呈现操作，悬停可查看说明。
