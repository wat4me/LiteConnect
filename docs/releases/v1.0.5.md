# LiteConnect v1.0.5

本次更新为 AI 会话加入图片输入和后台任务提示，改善长会话管理、窗口切换后的恢复体验及模型配置界面。

## AI 图片输入

- 支持选择图片、粘贴截图和拖入图片，可预览、移除，也可只发送图片。
- 图片随会话历史保存，支持历史预览、重试和编辑重发；图片参与上下文预算及压缩摘要。
- 在模型设置中勾选“支持图片输入”后启用，适用于支持图像识别的 OpenAI 兼容 Chat Completions 接口；中转服务也需要支持图片消息。
- 每条消息最多 4 张，支持 PNG、JPEG、WebP；处理后每张最大 5 MiB，最长边缩至不超过 2048 像素。图片保存在本机，不需要图床。

## 长会话与恢复

- 成功压缩上下文达到 3 次后提示新开会话，也可继续当前会话；提醒不会自动清空历史。
- 收起的时间线最多显示 12 个定位点，并随可用高度减少；展开后仍可定位全部轮次。
- 修复切换 SSH 窗口或重新打开 AI 面板后当前对话变成新对话的问题，保留各窗口的会话和草稿。
- 修复时间线收起后滚动条残留的问题。

## 后台任务状态

- AI 面板显示当前 SSH 窗口的后台任务数量，展开可查看命令、状态和退出码，以及最近已结束的任务。
- 收起面板后，AI 入口保留运行数量；主机和终端标签显示活动图标，切换窗口仍可辨认任务所在窗口。
- 标识跟随实际 SSH 后台任务的开始、结束、失败、超时和取消状态，普通模型思考不计入；非零退出码显示为失败。
- 后台命令可在 AI 回复结束后继续执行；关闭或断开对应 SSH 连接会取消任务。

## 模型配置与界面

- 获取模型时读取接口明确提供的上下文长度，并为已有模型更新自动信息；手动设置始终优先。
- 上下文显示接口信息、本地模型目录、名称推断或默认预算等来源，未识别时提示按实际限制填写。
- 提供商的编辑、删除操作常驻显示；模型右侧可直接设为默认或删除，无需展开配置。
- 修复图片输入复选框、模型列表标题、操作按钮和默认标签的文字对齐，沿用主题及自定义颜色。

## SFTP

- 优化窄侧栏下的工具栏，次要功能收进“更多”，避免缩窄面板后按钮拥挤或被截断。
- 区分目录差异与跟随终端目录的图标，减少功能混淆。
