# LiteConnect v1.0.8

本版本汇总 v1.0.7 之后的更新，重点改善 AI 后台任务续答与交互提问，新增 Anthropic Messages 协议和缓存用量统计，并完善 SSH 连接失败反馈及界面一致性。

## 后台任务：结果及时续答，执行时间可见

- 修复后台任务快速完成后，AI 仍停留在等待状态的问题。AI 忙时在下一次模型请求前交付结果，空闲时自动继续回复；刚给出等待说明时，也能在同一回复内接着分析。
- 完成结果直接进入所属对话上下文，并保留在历史中；无需为了读取已交付的结果再次调用 `get_job`。需要进度或更多输出时仍可主动查询。
- 后台结果统一显示为可展开的任务卡片，减少原始通知与普通回复混排造成的困惑。
- 运行中每秒更新已执行时间，完成、失败、超时或中断后保留最终用时。计时使用本地状态，不额外轮询服务器。
- SSH 侧栏采用紧凑两行布局，独立 LiteAI 宽页面采用单行布局，窄窗口自动调整。
- 自动续答继续限定在任务所属对话；主动停止或关闭会话后，不会因后台结果再次唤起该会话。

## AI 主动提问与自定义回答

- AI 可通过问题卡片收集缺失信息或请用户选择方案，支持单选、多选及文字回答。
- 每题提供“其他／自己填写”，可填写自己的答案或补充说明，无需受限于 AI 给出的选项。
- 多个问题逐题展示，使用“〈 1 / 3 〉”翻页并保留已填答案，最后统一提交。
- 提问时卡片替换底部输入框，避免选项和提交区域被遮挡；长内容可在卡片内滚动。
- 支持跳过本组问题或停止回复；问题与回答保留在会话历史中。提问与操作审批分别处理。
- 定时巡检不提供提问工具，缺少信息时记录到报告中，不等待人工回答。

## Anthropic Messages 与用量统计

- 提供商新增 Anthropic Messages（Claude）协议选项，覆盖流式回复、图片、多轮工具调用、后台续答、巡检和上下文压缩。已有提供商继续使用原有的 OpenAI 兼容协议。
- 支持获取 Anthropic 模型列表与上下文信息；服务返回带签名的思考内容时，保留原始内容供后续请求使用。当前未提供扩展思考模式开关。
- 回复用量细分为缓存命中输入、非缓存输入及输出，Claude 缓存写入单独列出；工具调用和压缩请求的用量累计到本轮回复。
- 修正流式统计快照重复累计的问题。接口缺失或仅部分返回的用量明确标注，不把未知值当作零，也不估算计费金额。

## 模型设置与上下文

- AI 设置按“模型与接口”“会话与上下文”“执行权限”“通知”分区，分别适配独立 LiteAI 页面与 SSH 侧栏。
- LiteAI 首页增加管理模型入口；输入区模型旁显示上下文占用圆环，便于查看当前使用情况。
- 模型设置展示上下文容量来源，支持手动覆盖、单次输出上限及压缩后保留近期原文的预算。
- 统一上下文预算与压缩处理，保留近期完整对话轮次，并改善压缩及中断后的工具执行记录，减少已执行操作或后台结果丢失。

## 会话操作、SSH 连接与界面

- 双击服务器卡片或列表行可直接开始单机 AI 会话；单击继续用于选择服务器和跨分组多选。
- 左侧已打开会话增加关闭按钮。关闭当前会话返回服务器列表，关闭其他会话不切换页面；历史、草稿和可复用 SSH 连接保留。
- SSH 连接失败后保留原因并提供重试入口，超时、网络不可达和认证失败等情况不再仅依赖短暂提示。LiteAI 重试保留原历史会话目标。
- 缩小连接取消按钮；调整错误提示的位置、宽度和换行，避免遮挡标题栏与系统窗口按钮。
- 统一图标、字号、间距、控件和主题样式，为关闭、断开、停止、跳过等操作使用更明确的图标语义。部分通用图标复用 Lucide，并补充来源与许可说明。
- 优化 Docker 日志搜索、自动跟随、跳到最新及持续输出时的定位，改善窄面板操作布局。
- 修复 Windows 开发版任务栏因旧 Electron 快捷方式冲突而显示错误图标的问题。

## 更新与验证

- 修正 Windows 安装包名称与自动更新清单引用不一致的问题。发布流程等待 Windows、macOS、Linux 构建全部完成后，再统一公开安装包与更新清单。
- 沿用已有连接、设置和会话数据，无需重新导入。
- 发布准备检查：类型检查、lint、国际化检查、生产构建、主进程加载检查通过；298 个单元测试文件完成，2175 项通过、1 项跳过；Electron UI 回归覆盖 72 个布局用例及 5 个主题。
- 当前主分支 GitHub CI 与 Windows 打包检查已通过；正式标签发布时仍会执行三平台测试和打包。
- Anthropic 适配已通过协议及契约测试，尚未使用真实 Claude API 密钥完成联调；实际服务兼容性仍需联调确认。
