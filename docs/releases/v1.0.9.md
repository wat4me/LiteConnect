# LiteConnect v1.0.9

本版本汇总 v1.0.8 之后的更新，重点完善 AI 文件传输、会话待办与长对话体验，并纳入前三批架构治理：依赖边界、SFTP 跨进程契约和服务退出生命周期。

## AI 文件传输与上传冲突处理

- AI 上传、下载共用 SFTP 传输能力。会话顶部可查看进度、速度和完成状态，按服务器及方向分组，支持取消、清理已结束记录和打开下载目录。
- 传输按发起对话和线程隔离，切换模块或暂时离开会话界面后仍可继续；停止传输中的 AI 请求会取消对应实际传输。
- AI 下载未指定本地路径时使用设置中的默认目录，结果返回实际保存位置；明确区分本地电脑与远端服务器，并校验 Windows 本地路径。
- 拖拽文件或选择文件夹后直接加入上传流程，扫描时显示已发现文件数量。只有实际遇到同名文件才询问，可保留两份、覆盖或跳过，并应用到本批后续冲突。
- 上传冲突弹窗由应用统一管理，关闭文件或 AI 面板后仍可处理；取消仅作用于当前批次，已完成文件保留。

## 会话待办与连接操作

- LiteAI 已打开会话用铃铛标记等待回答或操作确认，显示待处理会话数量；侧栏收起时保留提示点。
- 从“去处理”提示或通知进入时，打开待办所属的 LiteAI 会话或 SSH AI 侧栏，保留运行中的请求和已填答案。
- 提问草稿在切换会话和组件重新创建时保留，提交失败后可继续修改重试；未提交答案仅保留在当前应用运行期间。
- 服务器列表与卡片增加独立的断开连接入口。确认后只断开点选服务器的 AI 专用连接，保留历史和服务器选择，普通 SSH 终端不受影响。
- 完善共享连接上的断开、取消和重连处理，避免迟到结果修改已离开的会话或 Docker 页面。

## 长对话、流式渲染与会话操作

- 优化流式 Markdown、长会话滚动及多服务器详情的按需渲染，保留阅读位置和暂停跟随状态，减少切换界面时的重复工作。
- 完善消息复制、编辑、重新生成、图片预览、上下文用量和模型菜单的展示与操作。
- 支持清空当前对话，清空前确认；保留其他历史、草稿和 SSH 连接，保存失败时恢复原有对话。
- AI 工具按会话加载文件传输、交互式终端等可选能力，加载结果随会话保存；加载本身不会执行远端操作或授予执行权限。

## 架构治理与退出可靠性

- 补齐纯逻辑层的平台依赖限制、MCP 与 SSH 的适配边界，并将架构正反例检查纳入现有 lint 流程。
- 统一 SFTP 的共享 IPC 契约，对渲染端、preload 和主进程的参数、返回值及事件载荷进行编译检查，保留现有 API 和通道名称。
- AI、MCP、巡检调度器及通知器由应用装配层统一构造和管理，IPC 注册只接收已构造服务；保留 SSH、Docker 与数据库各自的连接生命周期。
- 退出时先停止接单和取消任务，再限时等待最终回复保存、巡检和 HTTP 收尾，最后释放连接并关闭存储。迟到的初始化不能重新开窗或启动服务。
- 加强后台续答、并行巡检、Webhook、HTTP 监听和更新下载确认的退出竞态处理；等待超时后继续退出，并沿用已有的中断恢复机制。
- 统一 npm 锁文件和依赖基线检查。前三批治理已完成，巡检面板与 App 的职责拆分继续按后续计划推进。

## 更新与验证

- 沿用已有连接、设置和会话数据，无需重新导入。
- 架构治理定稿通过全量单测：334 个文件、2422 项通过、1 项跳过；类型检查、lint、生产构建及隔离 mock Electron 退出检查通过。
- 发布准备补充通过 7 组 Electron UI 回归，覆盖 162 个布局场景，以及提问草稿、待办跳转、独立断开、上传冲突、传输取消和离开面板后完成等流程。
- Windows x64 安装包按锁文件中的 Electron 41.2.1 构建，安装包与自动更新清单的大小及 SHA-512 一致；打包后的 SSH、MySQL、PostgreSQL、Oracle 驱动和 Bash WASM 资源加载检查通过。
- 发布流程等待 Windows、macOS、Linux 构建和打包全部完成，并校验三平台自动更新清单后，再统一公开 Release。
- 协议、IPC 与生命周期回归包含 mock 验证；未以真实 SSH、数据库或模型服务完成全链路联调。Windows 和 macOS 安装包继续沿用现有未签名发布方式。
