# LiteConnect v1.0.14

本版本更新 SSH 和数据库工作区的布局，改进终端命令历史、SQL 执行反馈和 Windows X11 转发。

## SSH 工作区与界面

- 主机标签移入窗口标题栏。主机和终端标签栏溢出时可以用箭头或滚轮横向滚动，切换标签时会自动显示当前项。
- 终端标签支持右键重命名，名称保存在工作区中。单终端且没有分屏或 Docker 标签时会收起子标签行，可以从当前主机标签新建终端。
- SFTP 路径栏支持点击面包屑返回上级，过长路径折叠进菜单，也可手动编辑路径。
- 统一常用按钮、菜单和选中状态，更新明暗主题配色。收紧停靠面板间距，并保留面板之间的分割线。

## 数据库查询

- 调整 SQL 编辑器、执行工具栏和结果区，显示当前执行范围和耗时，优化结果网格的数值对齐。
- 查询失败时显示错误摘要、详细信息和可用的错误码。遇到可重试错误时，可以在原连接和数据库上重试符合只读条件的查询。

## 终端、监控与 LiteAI

- 命令建议过滤误采集的提示符、未完成的命令和常见失败命令。可用 `Shift+Delete` 移除当前选中的历史建议。
- 合并监控告警设置入口，进度条颜色按已配置的告警阈值变化。
- 阅读历史消息时，AI 的新内容会通过提示告知。修复部分 Markdown 链接因转义而无法正确打开的问题。
- 修复 Windows 上 VcXsrv 读取 X11 授权文件的兼容性问题。自动启动失败后短时间内跳过重复尝试，可在设置中手动测试重试。
