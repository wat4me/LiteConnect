# LiteConnect v1.0.2

这次更新重点改善 AI 会话资料管理、SSH 终端在高延迟连接下的输入体验，以及 SFTP 路径书签。还完善了命令历史隐私控制、分屏交互和更新检查。

## AI 会话

- **会话资料成为固定背景资料。** 可从本机选择 Markdown 文件，或读取当前 SSH 服务器上的 `.md` / `.markdown` 文件。应用保存添加时的内容快照；当前对话及这台服务器之后新建的对话，每次提问都会将其发送给 AI。每台服务器最多保存 5 份，每份不超过 32 KB。文件内容作为背景资料，不会绕过现有工具权限。
- **资料更容易查看和管理。** 输入框里的加号用于添加资料，已添加的文件在后面平铺显示。悬停可查看来源和路径，点击可预览已保存的内容，并检查原文件是否变化；原文件更新后，由用户确认才刷新快照。移除时可选择“仅当前对话”或“当前及后续对话”，明确控制新对话是否继续自动加载。
- **历史会话更容易找回。** 支持修改标题、按标题或消息正文搜索、置顶。置顶会话排在前面，且不会被会话数上限自动清理。会话历史仍按 SSH 主机地址和端口隔离。
- **简化操作区。** 移除了 AI 侧栏顶部的“清空当前消息”及其“更多操作”入口；历史面板仍可管理整条会话和全部历史。发送失败时会保留尚未发出的输入，方便重试。

## SSH 终端

- **降低交互输出的额外等待。** 对键入后收到的小段服务器输出，优先写入终端，而不再总是等待下一次批量渲染；大量输出仍按批处理，避免持续刷屏时卡顿。
- **新增可选的“本地预览回显”。** 在“设置 → 终端”开启后，识别到常见 Shell 提示符时，普通英文、数字和符号按键会先以浅色文字预览；收到服务器回显后再校正。开关默认关闭，按键始终照常发送到服务器。自定义提示符、交互程序和敏感输入场景建议保持关闭。
- **改进命令建议历史。** 可设置通配符隐私规则，匹配的命令不写入本地建议历史，也可一键清空本地历史。对常见的命令不存在提示增加识别，并延长等待远端输出的时间，减少失败命令误入历史。执行时间较长的命令仍可能先被保存，不能把此机制当作完整的命令成功判断。
- **分屏行为更明确。** 进入 SSH 分屏时自动收起 AI 侧栏，退出后恢复原先显示状态；跨主机分屏时 SFTP 侧栏也会按原有规则暂时隐藏。分屏期间禁用会重新打开 AI 的入口。

## SFTP 与应用体验

- **路径书签。** 可按当前连接或所有连接保存路径书签，支持重命名、修改路径、排序及删除；也可从当前目录直接收藏。打开书签目录时会暂停跟随终端目录，避免刚跳转又被终端路径覆盖。修复连续保存书签时可能回滚的问题。
- **检查更新更可靠。** 更新检查超过 20 秒会给出超时提示，便于在网络不可用时重试。关闭到托盘的处理覆盖已经打开的应用窗口。
- **开发测试更安全。** 开发版默认使用独立数据目录；可在开发者工具中为 SSH 输出模拟延迟并记录输入耗时。模拟设置仅对开发版的当前窗口生效，关闭窗口后不保留。
- **内部整理。** 拆分 AI、数据库和 SSH 的部分模块，改进按需加载；这部分主要用于降低后续维护和回归风险。

## 升级说明

- 会话资料保存的是文件内容快照，原文件的后续改动不会自动同步。可在资料预览中检查并手动刷新。
- 本地预览回显默认关闭；升级后如需使用，请到“设置 → 终端”手动开启。
- 命令历史隐私规则和清空操作只影响 LiteConnect 本地用于提示的历史，不会删除服务器 Shell 自己的历史。
