# LiteConnect v1.0.10

本版本重点改进连接管理、SSH 粘贴与长列表性能，完善 LiteAI 的执行记录和国际化，并接入三平台自动 X11 图形转发。

## 连接管理

- 支持多级分组，优化分组展开、收起、选择和跨组移动。
- 增加紧凑列表模式，调整导航、搜索、标签筛选、排序与工具栏布局；保留常用操作按钮和快捷键提示。
- 支持拖动连接卡片、列表行与分组进行排序或移动，无需只拖动狭小的把手。
- 调整连接信息层级，使用次数和最近连接时间保留在左侧信息区；清除筛选不再挤占搜索框宽度。
- 统一部分工具图标，补充悬停提示和无障碍标签。

## SSH 终端与粘贴

- 粘贴输入时自动回到终端底部。
- 多行粘贴确认框支持编辑，发送前可检查和修改内容；支持终端括号粘贴协议，减少多行内容意外逐行执行。
- 超长粘贴增加明确提示和大小限制；SSH、同步输入与容器终端统一处理相关边界。
- 优化浅色终端中带背景色文件名的对比度与光标样式。

## LiteAI 与国际化

- SSH 侧栏和 LiteAI 支持查看当前对话的命令执行记录，区分标准输出、错误输出、退出状态、超时、取消和输出截断。
- 完善命令风险判级与自动执行模式的配合，减少只读探测被误判后触发审批的情况；被禁止的操作仍不自动放行。
- 工具状态、输出截断提示和文件查找数量保持单行，长说明使用省略显示，悬停可查看完整状态。
- 优化执行工具时的上翻阅读：计时显示独立更新，滚动位置测量按帧合并，暂停跟随后减少重复扫描。
- “回到底部”改为圆形箭头按钮，保留文字提示和键盘操作；点击后继续跟随最新输出。
- 完善中英文界面、主进程错误消息与工具说明，补齐语言切换和翻译检查。

## 性能

- 连接列表、分组侧栏、SFTP 目录树、数据库结果和 Docker 日志采用或完善虚拟列表，减少大量条目同时挂载。
- 优化行高测量、滚动锚点、日志跟随和尺寸变化处理。
- 限制并发延迟探测，减少隐藏页面和空闲光标效果的后台工作。
- 增加页面渲染性能诊断，便于查看帧间隔、DOM 数量和加载指标；这些数据用于诊断，不代表物理屏幕刷新率。

## 自动 X11 图形转发

- 普通 SSH 连接默认使用“自动”模式，仍可选择“关闭”或“自定义”；AI 专用连接和后台监控不启动图形显示服务。
- Windows 安装包内置便携 VcXsrv，按需启动带认证的独立显示服务，无需用户手动启动或运行额外安装向导。
- macOS 自动检测、按需唤起 XQuartz；缺少组件时提供官方安装页面入口，安装后可能需要注销并重新登录。
- Linux 复用桌面的 Xorg / XWayland 显示服务与认证信息；无桌面环境或缺少认证时给出提示。
- 远端图形程序显示为本机桌面窗口。显示服务不可用时，普通 SSH 连接仍可继续。
- Windows 自动模式使用独立认证文件和每次 SSH 连接的转发 cookie，不采用关闭访问控制的启动方式。

## 更新说明

- 沿用已有连接、设置和会话数据，无需重新导入。
- 本地完整测试通过：357 个文件、2594 项通过、1 项跳过；类型检查、代码规范、国际化和生产构建通过。
- 相关界面回归与 Windows 本机图形窗口测试通过。macOS / Linux 的接入逻辑有自动化覆盖，实际桌面图形窗口仍需对应系统验证。
- Windows、macOS、Linux 安装包与自动更新清单由发布工作流统一构建，全部完成后公开发布。
- 停止 AI 请求不等于撤销已完成操作，也不能保证终止已脱离 SSH 通道的远端进程。已启动的后台任务需要单独停止；部分文件和服务工具尚未统一接入取消链路。
- Windows 和 macOS 继续沿用未签名安装包的发布方式。
