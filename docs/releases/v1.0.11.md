# LiteConnect v1.0.11

本版本完善服务器知识管理，将后台命令与文件传输统一到浮动任务入口，并改进模块切换、设置保存和运行稳定性。

## 服务器知识

- 知识文档按服务器身份保存在本机，支持 Markdown 编辑、导入导出、修改历史、版本恢复与编辑冲突保护。
- 增加“关闭 / 只读 / 可更新”三档模式。只读时，AI 继续使用已有知识并按需搜索、读取，但不能新增或修改知识；用户仍可手动管理文档。
- 知识模式独立于命令执行权限，多服务器会话可以逐台设置。可更新模式继续遵循全局执行权限。
- 模式选择框提供悬停说明，解释当前模式的知识读取、AI 写入和手动管理范围。
- 短知识可选择每轮附加，详细资料按需读取；支持可选的来源关联，并限制上下文占用。
- 旧会话资料迁入服务器知识，保留不同的正文快照并去重；迁入的文档默认按需读取。
- 升级保留已有启用状态：原来关闭的仍关闭，原来启用的保持可更新。关闭后保留文档和版本历史，已经发送到对话中的内容不会被撤回。

## 统一任务入口

- AI 聊天区中的后台命令、上传和下载合并为一个浮动入口，角标显示进行中的总数，展开后分组查看。
- 支持上下左右四边吸附和位置记忆；点击展开，点击面板标题图标收起。
- 圆球与面板之间使用连贯的形变动效，遵循系统“减少动态效果”设置。
- 保留命令状态、耗时、输出与停止操作，以及文件传输进度、速度、取消、清理已结束记录和打开下载文件夹等操作。
- 关闭或切走 AI 界面时隐藏浮层，后台任务继续按原有逻辑执行；任务面板字体更紧凑，适配窄侧栏和完整工作区。

## 导航与设置

- 增加 SSH / 数据库 / AI 模块快切，完善模块切换、全局跳转和通知跳转时的离页保护。
- 设置按差异保存并跨窗口同步，保留未保存草稿，支持加载失败后重试。
- 即时应用终端重连和监控设置，壁纸保存失败时保留旧图并允许重试。

## 打包与更新

- 优化 X11 准备流程，增加可选的 macOS Developer ID 签名及公证配置；实际签名状态取决于发布环境配置。
- 安装包与自动更新清单继续由发布工作流统一构建，全部平台完成后再公开发布。

## 验证

- 本地全量测试：371 个测试文件通过，2687 项通过、1 项原有跳过。
- 代码规范、国际化、渲染进程／主进程／接口类型检查和生产构建通过。
- 知识库界面回归覆盖三档模式、首次确认、手动管理、导入导出、冲突保留草稿、版本恢复、旧资料迁移和服务器隔离；完成 12 组文档布局、48 组知识入口布局与 4 组关闭／缩放检查。
- 任务与传输界面回归覆盖四边吸附、位置记忆、形变动效、传输进度和会话隔离。
- 本轮未进行 macOS／Linux 实机验证或真实远端 SSH／SFTP 烟测；这些环境的运行情况仍需对应设备和服务器确认。
