# LiteConnect v1.0.3

这次更新增加服务器资源告警与后台监控，改善托盘、SFTP 和 X11 转发的使用体验，并修复 SSH 重连异常。

## 服务器监控

- **资源告警。** 可为每台已保存的服务器单独设置 CPU、内存使用率阈值和每 24 小时的通知上限。连续 3 次采样超限后才发送系统通知；持续超限时至少间隔 30 分钟。点击通知可打开对应的监控面板。告警默认关闭。
- **无终端时继续监控。** 可单独开启后台监控。应用运行期间，即使没有打开该服务器的终端，也会建立后台 SSH 连接采样；退到托盘后继续运行，退出应用后停止。设置页可查看状态并手动重试。首次连接仍需在终端中确认主机密钥；需要交互输入的认证不会在后台弹窗。

## SFTP 与窗口

- **SFTP 字号可调。** 在“设置 → 文件”调整 SFTP 文件列表字号，并修复长文件名影响其他目录文字显示的问题。
- **跟随终端更易识别。** 工具栏改用文件夹同步图标表示跟随终端目录，开启时仍有高亮提示。
- **托盘恢复。** 应用退到托盘后，从系统再次启动 LiteConnect 会恢复并聚焦原窗口，避免出现第二个实例；同时修复部分窗口恢复场景。
- **连接菜单图标。** 调整“在新窗口打开”“测试连接”和“置顶”的图标，减少与其他功能图标混淆。

## SSH 与其他修复

- **X11 转发与重连。** 本地 X11 连接或单个转发通道失败时，在终端显示提示，不再误判为整条 SSH 连接断开。合并同一会话的并发重连请求，避免重复断开已经恢复的连接；本地 X11 套接字启用低延迟发送。
- **连接与 AI 提示。** SSH 连接失败信息显示服务器名称和地址；修复 AI 会话中带代码格式的网址可能被错误拼接的问题。

## 升级说明

- 资源告警和无终端后台监控都需要按服务器主动开启。后台监控会建立额外的 SSH 连接；不需要时可在监控面板或“设置 → 连接 → 后台资源告警”中关闭。
