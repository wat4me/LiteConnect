# LiteConnect v1.0.7

本版本汇总 v1.0.6 之后的全部更新，重点新增 LiteAI 独立工作区、多服务器协同会话、定时巡检与外部通知，同时改进连接管理、终端同步输入和 SSH 连接可靠性。

## LiteAI：一个会话协同管理多台服务器

- 从左上角模块菜单切换至 AI，即可进入独立的 LiteAI 工作区，无需先打开 SSH 终端。
- 支持手动选择 1 至 20 台已保存服务器。选择一台进行单机管理，选择多台则在同一个 AI 会话中共享上下文，适合应用、数据库、网关等服务部署在不同服务器上的排查与联调。
- 服务器卡片和列表行常驻勾选框，单击卡片即可选择或取消。单台与多台统一从底部“开始会话”进入，移除卡片内重复的单机对话和断开按钮。
- 支持跨分组多选、选择当前搜索结果、逐个移除和清空选择。搜索、筛选以及切换卡片 / 列表视图均保留已选服务器；底部操作区固定显示，服务器列表独立滚动。
- “新建对话”弹窗同样支持按分组搜索和多选，并沿用服务器页面已有的选择；旧版单机会话可预选当前主机，再新建协同会话。
- 顶部明确显示“本会话管理 N 台”和“已连接 X/N”，直接展示前三台服务器名称，可展开查看完整清单、连接地址和状态。侧栏会话标题增加管理台数标签。
- AI 系统上下文包含用户所选服务器的名称、地址、用户、分组和备注，便于识别各服务器的角色；密码、私钥等认证凭据不提供给模型。
- 工具调用必须指定所选范围内的目标服务器。应用校验连接范围，以及后台任务、交互式 PTY 的服务器归属，审批与工具结果均标注目标主机。
- 多服务器查询或比较时，引导 AI 先给跨服务器汇总表，再提供各主机详情。页面可自动折叠可识别的主机标题详情，展开后仍能查看完整内容及复制代码；汇总、整体结论和下一步建议保持可见。
- 新会话的管理范围随历史保存，恢复时重新连接原范围。修改管理范围通过新建会话完成，AI 不会自行加入其他服务器。
- 任一范围内服务器断开后暂停发送，可重新连接并继续原对话；不会自动把操作转发到另一台主机。
- LiteAI 使用专用 SSH 连接，与普通 SSH 终端独立。切换工作区不影响已有会话、草稿与任务；关闭范围会话保留历史和可复用连接，并停止该会话的后台结果自动续答。
- 修复已打开某台服务器后，再从新建会话选择同一服务器时出现 “An object could not be cloned” 的问题，复用连接时保留原会话的消息和草稿。

### 工作区布局与历史管理

- 移除重复的工作区品牌标题、侧栏底部管理入口，以及服务器页面的大标题说明区，集中使用顶部工具栏。
- 缩小服务器卡片，保留名称、备注、地址和连接状态；底部未选择时使用紧凑提示，选中后展示所选清单。
- 提供全部 / 已连接筛选、名称 / 地址 / 分组 / 备注搜索、刷新和连接管理入口，卡片与紧凑列表视图会记住用户选择。
- 服务器浏览与对话内的服务器选择均保留分组，支持分组折叠和按分组名称搜索。
- 分组内优先展示置顶服务器并显示图钉；从连接管理返回或应用重新获得焦点时同步连接信息。
- 已打开会话与历史会话使用各自固定的空间和独立滚动条，列表增多不会持续挤压其他区域。
- 历史按日期分组，默认展示最近 5 条，支持展开更多、再次收起；展开和收起保持分区高度，收起后回到历史列表顶部。
- 仅实际打开的对话进入当前会话列表，避免把为协同会话建立的每条底层连接都重复显示为单机会话。
- 兼容旧版 LiteAI 单服务器历史、SSH 侧栏历史及已有草稿；新建协同会话的历史独立保存。

## 定时巡检与多服务器报告

- 在 LiteAI 中新增“定时巡检”，可选择 1 至 10 台已保存服务器，填写检查内容并创建计划。
- 支持每 15 分钟、每小时或每 24 小时执行，也可按本机时区指定每天或每周的固定时间；页面显示下次执行时间。
- 支持立即执行、暂停、编辑、删除计划，以及中断当前执行。手动立即执行不改变计划原有的下次触发时间；暂停的计划仍可手动执行。
- 多服务器巡检可串行或最多 5 台并行。每台服务器使用独立 SSH 连接和 AI 上下文，一台失败仍继续其余主机，完成后汇总差异、共同异常与处理优先级。
- 巡检强制只读，不继承交互聊天中的自动修改权限；使用前台命令通道，结束后释放专用连接，不改变正在聊天的对话。
- 支持为计划固定模型与服务商；未指定时使用当前活跃配置。
- 报告提供总体结果、每台主机的健康状态、检查是否完成、失败原因及可展开的工具详情，区分“工具执行成功”和“服务器健康”。依据不足的健康判断标为“需复核”。
- 任一主机、工具或汇总失败时保留已完成结果，并明确显示执行失败；中断只影响本次执行，计划继续保留。
- 到期计划进入全局串行队列，同一时间执行一项计划，单次最长 10 分钟。当前最多保存 50 个计划和最近 200 条执行记录。
- 应用运行、最小化到托盘或收起工作区时均可按计划巡检；退出应用后停止执行。重启会清理遗留的运行状态，逾期计划最多补执行一轮。

## 巡检外部通知

- 新增通用 JSON Webhook 配置，可选择仅通知异常、失败或需复核，或在每次执行结束后通知；主动中断不发送通知。
- 提供保存并发送测试入口，便于核对接收端；通知地址和可选 Bearer 令牌加密保存，令牌不回传页面，也不进入 AI 上下文。
- 通知包含执行编号、计划名称、执行与健康状态、报告摘要和各主机状态，不包含原始工具输出或通知凭据。
- 通知独立发送，最长等待 8 秒，失败不会改变巡检结果或阻塞下一项计划；发送状态可查看，不自动重试。
- 飞书、钉钉等平台可通过接收服务转换消息格式；当前提供通用 JSON 格式，不直接套用各平台专有机器人协议。

## 连接管理

- 新增置顶、最近连接与颜色标签智能视图，更快找到常用服务器。
- 搜索覆盖连接名称、主机、备注、颜色标签和分组，支持从当前分组扩展到全部分组。
- 优化分组选择与折叠：选中分组展开自己的连接，手动折叠保留当前分组，不会被状态刷新反复撑开。
- 优化窄窗口下的连接工具栏、分组长名称、计数及常用操作布局，并同步 LiteAI 的置顶展示。

## 终端实时同步输入

- SSH 工作区新增“同步输入”，可选择至少两个可写终端，在任意一个选中的终端输入时向其他目标发送相同字符。
- 支持中文、退格、回车、Ctrl+C、Tab、方向键、命令建议补全及确认后的粘贴；未选中的终端不接收同步输入。
- 顶部常驻显示同步目标和停止入口。修改目标会先暂停同步；断开、只读或关闭的终端移出目标，目标不足两个时自动停止。
- 进入 Docker 工作区会停止同步，重启应用后不自动恢复。同步输入发送相同字符，各服务器的 Shell 状态和补全结果仍由各自环境决定。

## SSH 可靠性与其他改进

- 区分主机信任确认、用户取消和真正的连接失败，减少首次连接与自动重连过程中的错误提示。
- 主机信任与交互认证弹窗按连接排队，并注明目标；连接结束、取消或认证超时后移除过期弹窗。
- 网络握手默认等待 20 秒，验证码等交互认证允许用户输入 120 秒；提交后恢复网络等待期限，目标主机与跳板机分别计时。
- 连接列表显示握手、跳板机、认证、等待输入和打开终端等阶段；取消会终止后台连接，晚到回调不会再创建终端。
- 每个终端独立计算重连次数，采用带随机延迟的指数退避，并限制相同目标与跳板机组合的并发握手。
- 主机指纹在成功保存后才更新信任状态，避免磁盘写入失败时出现内存与持久化状态不一致。
- 改善会话日志的磁盘背压和快速关闭处理，日志写入异常不会中断 SSH 会话。
- 优化 SFTP 长文件名的截断、悬停完整路径和窄侧栏布局，避免目录树撑宽面板或遮挡操作。
- AI 工具与后台任务统一展示用途说明和执行状态，后台结果返回所属对话，避免影响同一服务器上的其他会话。

## 使用与升级说明

- SSH 侧栏 AI 仍固定管理当前终端；需要一个对话协调多台服务器时，请使用 LiteAI 的多选会话。
- 多服务器聊天共享上下文，工具调用仍按模型调用顺序逐项执行；定时巡检支持独立上下文下的并行检查，两者执行方式不同。
- 自动巡检依赖应用处于运行状态；首次主机信任、失效凭据或需要交互认证的连接，请先在前台处理。
- 本次升级沿用已有连接、设置和会话数据，无需重新导入连接。
- 发布前本地验证：类型检查、lint、国际化检查、278 个测试文件（2011 项通过、1 项跳过），以及覆盖 72 个布局用例和 5 个主题的 Electron UI 回归。
