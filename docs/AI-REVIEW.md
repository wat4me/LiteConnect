# LiteAI 模块梳理（2026-10-20）

本次基于工作区当前代码（含已有未提交改动）检查执行链、会话生命周期和 UI 实现，并使用模拟模型、SSH 与历史数据运行回归。主进程已有清晰的服务边界，当前更值得优先投入的是前端异步状态一致性、交互入口统一和大组件的职责收敛。

## 当前结构

| 层级 | 入口 / 模块 | 职责 |
| --- | --- | --- |
| 工作区 | `src/views/AiWorkspaceView.vue` | 服务器浏览、多选、已打开会话、历史与巡检入口 |
| 聊天 UI | `src/components/ai/AiSidebar.vue`、`AiChatView.vue` | 输入、模型与权限、审批、提问、流式消息与时间线 |
| 前端编排 | `src/composables/ai/workspace/useAiWorkspace.ts`、`useAiChat.ts` | 连接映射、会话切换、草稿和消息投影 |
| 前端状态 | `src/composables/ai/chat/` | 会话状态、历史与设置；不另建一套消息存储 |
| 执行 | `electron/ai/execution/` | 请求、工具轮次、停止、检查点、上下文压缩与后台续答 |
| 协议 | `electron/ai/providers/` | OpenAI 兼容、Anthropic 编解码和 HTTP/SSE |
| 工具 | `electron/ai/tools/` | 目标路由、权限判定、审批、文件 diff 与 MCP 调用 |
| 历史和范围 | `electron/ai/history/`、`workspace/` | 持久化、图片、专用 SSH 连接与不可变服务器范围 |
| 巡检 | `electron/ai/schedules/` | 定时调度、多机独立上下文、汇总和 Webhook |
| 共享规则 | `shared/ai*.ts` | 消息格式、预算、用量、工具目录、范围与权限规则 |

交互链路为：页面 → chat facade → preload/IPC → 执行服务 → 协议与工具 → 历史持久化 → 页面投影。巡检通过适配层复用执行服务，不依赖聊天页面保持挂载。

应继续保持的边界：SSH 侧栏固定操作当前终端；LiteAI 使用专用连接和保存的服务器范围；巡检使用独立连接、上下文和只读权限。界面可以复用，连接生命周期与历史身份不能直接合并。

## 本次修正

1. **刷新乱序。** 焦点、模块激活、手动刷新和后台回复完成都可能刷新数据。较早的服务器列表返回后会覆盖较新列表，甚至移除已选服务器；历史索引同样可能回退。现在分别校验请求版本，只有有效请求能更新数据，旧请求也不能清除最新请求的加载状态或写入过期错误。组件销毁后忽略返回结果。
2. **会话建立期间的导航竞争。** 单台 SSH 已连接但范围或历史尚在加载时，`connectingId` 可能已经清空。现在会话切换、历史恢复和选择入口统一检查操作锁；侧栏按钮同步禁用，避免 UI 可点击但处理函数拒绝，或两个流程争用当前会话。
3. **旧连接事件。** 关闭通知携带旧 SSH 会话编号时，不再清理同服务器的新连接；取消旧连接尝试的事件也不再移除已经连接的会话。当前连接真实断开仍正常处理。
4. **能力文档。** 更正 Claude 图片支持、定时巡检 UI 和执行服务调用方的过期描述。

补充 6 项异步回归，覆盖服务器刷新、错误返回、历史索引、销毁后的返回、范围建立期间导航以及旧连接事件。

## UI 检查与建议

已查看本次 UI 回归生成的真实 Vue 组件截图：服务器列表、桌面浅色聊天与窄窗口聊天。它们使用模拟业务数据，不代表真实服务器执行结果。

- **保留现有信息架构。** 服务器 → 选择范围 → 开始会话的路径明确；已打开会话与历史分区、顶部范围信息和底部输入区都有独立位置。
- **已改善窄窗口聊天宽度。** 新增 `useAiWorkspaceRail.ts`，未设置偏好时宽度不超过 760px 的聊天默认收起侧栏；浏览服务器和巡检时展开。手动选择持久化后优先于自动布局。
- **已统一模型菜单键盘体验。** 补齐菜单和单选项语义、初始焦点、方向键、Home/End、Esc 焦点返回与 Tab 退出，并防止并发模型选择。
- **明确附件入口用途。** Markdown 固定资料、图片输入与上传部署文件是不同路径。现在部署文件需在对话中写本地路径，可以评估增加文件选择入口；真正传输仍必须走现有工具权限、目标校验与审批。

审批样式已随组件迁移，聊天与选择页面保留原视觉结构，仅调整窄窗口侧栏默认行为和菜单焦点样式。真实系统缩放、长主机名、多服务器长对话和原生认证弹窗仍需要实际环境验证。
