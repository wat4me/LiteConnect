# AI 会话使用指南

## LiteAI 独立工作区

在左上角模块菜单选择 AI，进入 LiteAI。点击左侧已保存的服务器，应用自动建立连接并打开该主机的 AI 对话，无需先打开 SSH 终端。首次主机验证、密码和交互认证沿用现有连接流程；工具操作仍遵守 AI 权限设置。

切换服务器保留各自当前对话、草稿和运行任务，切换回 SSH 或数据库模块也不会断开 LiteAI。工作区使用专用连接，普通终端的关闭不会影响它。顶部“断开连接”只关闭当前 LiteAI 主机；若 AI 正在回复或有后台任务，会先提示确认，断开后中止对应任务。重连进入空白对话，旧对话可从历史手动打开。

当前支持单台主机对话，服务器连接由应用管理；跨主机编排与定时运维计划后续接入。

## AI 会话图片附件

在 AI 设置 → 服务商 → 模型详情中勾选“支持图片输入”。仅在模型与当前接口都支持图片时启用；自定义模型和中转服务由用户明确设置，旧配置默认关闭。

输入框上方的图片按钮可选择 PNG、JPEG、WebP；也支持粘贴截图和拖入图片。每条消息最多 4 张，可只发送图片。缩略图可预览、移除，历史记录中的图片可继续预览，并随后续对话、重试、编辑重发提供给模型。

- 原始图片最大 20 MiB；最长边超过 2048 像素时缩小。优先保留 PNG，过大时转换 JPEG；处理后每张最大 5 MiB，一次模型请求的图片总量最大 20 MiB。
- 现阶段支持 OpenAI 兼容的 Chat Completions 图文消息：发送时将文字和图片转换为 `text` / `image_url` 内容块，图片使用 Base64 data URL，无需图床。Claude、Gemini 原生协议需要独立适配。
- 图片字节存储在用户数据目录的 `ai-images/<主机哈希>/<内容哈希>.image` 中。会话数据库只保存引用；仅当前会话加载图片，清理历史、删除消息或会话后回收无引用文件。
- 丢失图片、未启用图片支持、接口拒绝图片会明确报错，不会退化成纯文本请求。图片上下文用估算值参与预算，实际计费由服务商返回的 usage 决定。上下文压缩会把图片提供给摘要请求，原始历史仍保留图片。

测试覆盖消息序列化、上下文打包、图片独立存储及回收、模型配置，以及真实 Electron 中的选择、粘贴、拖入、预览、删除、图片单独发送与多主题布局。测试接口使用模拟响应，不会上传图片到真实服务。

## AI 长会话与上下文压缩

模型上下文预算优先使用手动配置（包括兼容旧配置的全局值），其次使用“获取模型”读取的提供商上下文信息，然后查本地 models.dev 目录、推断模型名称中的长度，最后采用 300000 token 的默认预算。默认预算不代表实际模型能力，未识别时请按接口限制手动填写。

兼容接口的 `/models` 返回 `context_length`、`context_window` 或 `max_model_len` 时，会缓存为模型的自动上下文信息，保存后供实际请求和压缩使用；不把通常表示输出上限的 `max_tokens` 当作上下文。再次获取会更新已有模型，手动配置保持优先。更换提供商地址会清除旧接口信息；修改模型 ID 后不沿用原 ID 的信息。模型设置会标注接口、目录、名称推断、默认预算或手动设置的来源。

上下文预计达到可用输入预算的 80% 时，先裁剪过长的工具输出；仍超过阈值时，将较早的完整对话轮次生成摘要，合并已有摘要，并保留近期上下文。摘要用于模型请求，不替换界面上的原始消息；历史保存数量仍受历史设置限制。

成功保存一次新的摘要检查点计为一次压缩。摘要请求分成多个批次仍只计一次，单独裁剪工具输出或失败不计入。计数随会话保存，修改消息导致摘要失效、历史裁剪或重启均不清零。已有旧摘要但没有计数字段时，从 1 次开始计数。

达到 3 次压缩后，输入区建议新开会话。用户可以继续当前会话，关闭该次数的提示；下一次成功压缩后再次提示。新开会话保留原会话历史，不自动携带旧摘要，计数从 0 开始。此提醒不强制终止会话。

收起的时间线最多显示 12 个定位点，小视口会进一步减少，始终包含第一轮、最后一轮与当前轮次。鼠标移入或键盘聚焦后显示全部轮次，可滚动跳转；再次展开会恢复展开列表的滚动位置。

全新打开的 SSH 窗口进入自己的空白 AI 会话，旧对话可从历史中手动打开。切换已有 SSH 窗口、关闭并重新打开 AI 面板时，恢复该窗口当前的会话和草稿。已加载的窗口状态优先于共用历史存储中的当前会话，避免同服务器的其他终端改变当前历史选择后覆盖本窗口。

## SSH 后台任务状态

AI 工具可通过 `exec(background=true)` 启动独立 SSH exec 通道。任务结束后，结果自动送回所属对话，由 AI 分析和继续处理，无需反复 `get_job`；需要进度或更多输出时仍可主动查询。AI 回复结束或收起面板不会终止已启动的后台命令；关闭或断开 SSH 会取消通道。普通模型思考、前台工具调用以及命令自行脱离通道创建的守护进程不属于此任务列表。

AI 面板显示当前 SSH 窗口的后台任务数量，展开可查看完整命令、起止时间、标准输出、错误输出和失败原因，以及最近五条已结束任务。正常完成隐藏退出码 0，非零退出码仍显示；详情限制高度并在内部滚动。侧边栏 AI 按钮显示当前窗口的运行数量；主机标签和终端标签显示活动图标，切换到其他窗口仍可辨认有任务在执行的窗口。审批和未读提示保留。

状态直接读取应用共享的 SSH 工具任务存储，覆盖 AI 和外部 MCP 发起的后台命令。任务启动、结束、失败、超时或取消后，主进程推送状态更新；组件共用一个订阅，不周期性查询。初次挂载读快照，并避免较旧快照覆盖实时事件。重启应用后不恢复已关闭的 SSH 通道任务。

AI 的自动续接只处理绑定到该对话的任务，外部 MCP 任务仅更新任务列表。AI 忙时结果排队，空闲时自动处理；连续自动续接最多三轮，新的主动调用重置限制。后续工具操作继续遵守当前权限设置。新建对话时，若当前 SSH 有运行任务，会先确认；确认后停止任务并禁用旧对话的自动续接，取消则保持原状。主动停止 AI 回复后，也不会被该对话的任务结果重新唤起。

底层执行入口与页面监听已经分离，侧栏和 LiteAI 共用执行服务。无页面调用当前只开放只读执行，运维计划尚未提供界面，开发接口见 [AI 执行服务](AI-RUNTIME.md)。
