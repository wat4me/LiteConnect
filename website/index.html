核心能力

演示里能点到的，也是应用里日常会用到的。

SSH 终端

多连接、多终端标签、分屏与命令片段；主机密钥指纹确认，断线自动重连，可独立窗口打开会话。

SFTP 与监控

目录浏览、上传下载与传输列表；底栏展示 CPU / 内存 / 磁盘，展开可看进程详情。

Docker

经现有 SSH 访问远端 docker.sock。容器列表筛选、启停重启、概览 / 日志 / exec 终端。

数据库

MySQL / PostgreSQL / Oracle。连接树、SQL 编辑器、结果与历史；可经 SSH 隧道连内网库。

AI 助手

OpenAI-compatible 接口。按会话隔离对话，历史保存在本地；回复中的命令可填入或发送到终端。

本地与安全

连接与凭据落在本机；敏感字段经系统 safeStorage 加密。known_hosts 管理主机密钥。

一条链路，多种场景

从登录主机到查库、看容器、问 AI——不必在多个工具之间来回切换。

01

本地优先

配置与历史在本机；密码不落明文（在系统密钥环可用时）。

02

经 SSH 触达内网

数据库隧道、Docker sock、监控命令都走现有会话，不必暴露远端 TCP API。

03

运维减负

全局跳转、快捷键、命令历史补全、危险 SQL 二次确认。
